# Batch Tab Excel Import Update

- Adds Import Excel to each Batch tab.
- Automatically prefers a workbook sheet whose name matches the active Batch tab.
- Smart participant matching priority: HR ID -> MIS/JW -> Name.
- Existing participants are merged/updated instead of duplicated.
- Information import can add genuinely new New Hire names and fill HR ID, MIS/JW, email, password, phone and notes.
- Attendance supports long rows and the app's wide attendance export.
- Quiz, Typing Test, Role Play, Certification, Nesting and Result import their own tab fields.
- Role Play avoids duplicate same Case ID/date entries.
- Certification Attempt 2 import remains conditional on Attempt 1 = Failed.
- Preview shows matched, new and needs-review/skipped rows before import.
