# Coverage & Dashboard Clarity Update

- Dashboard coverage card now explicitly represents coverage of Active/In Progress activities only: Attended assignments divided by required assignments.
- Coverage by LOB now shows the active activity names under each LOB, with covered/required counts and percentage for each activity.
- Coverage page is now session-first: sessions are listed directly with activity, LOB, trainer, date, attendance count/percentage and status.
- Clicking a session name or View details opens the existing full session detail page with attendance, result and notes.
- Session summaries now expose attended and absent counts in addition to total learner records.
