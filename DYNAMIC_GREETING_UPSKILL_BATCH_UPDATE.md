# Dynamic Greeting + Upskill Batch Update

This build includes the previous Daily Quiz / Daily Arabic & English Typing Test update and adds:

- Dashboard greeting uses the signed-in user's name.
- Greeting changes automatically by browser time: Good morning / Good afternoon / Good evening.
- Batch type: New Hire or Upskill.
- New Hire batches keep the existing workflow: manually enter names, add MIS/HR ID later, then graduate Passed trainees into Agents / Head Count.
- Upskill batches select existing Active agents from Head Count for the selected LOB. Search, select-all-shown and clear-shown are available.
- Upskill participants keep the same daily Attendance, daily Quiz, daily Arabic Typing, daily English Typing and Result workflow.
- Upskill agents are already official Head Count, so no Graduate action is shown for them.
- Batch list displays the batch type and supports a type filter.
- Dashboard Active Batches card shows the active New Hire / Upskill breakdown.
- Old batches are automatically treated as New Hire for backward compatibility.
