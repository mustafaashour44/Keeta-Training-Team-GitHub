# Exam Library Update

- Renamed sidebar/page from **Exam Link** to **Exam**.
- Split the page into two organized areas: **Exam Packages** and **Question Bank**.
- Existing exam links are preserved and automatically treated as Exam Packages.
- Exam Packages keep name, LOB, type, URL, status, notes, owner and created date.
- Question Banks require only a name and LOB (plus optional status/notes); no URL is stored.
- Existing owner/admin edit and delete permissions remain in place.
- Added independent search for packages and search + LOB filter for Question Banks.
