# Graduation + LOB Skill Import update

- New Hire `Graduate to Agents` is available to Mustafa (Main Admin) and the trainer assigned to / owning that batch.
- Other trainers cannot graduate trainees from someone else's batch.
- Agent roster Excel/CSV import keeps the canonical website LOB names while accepting these LOB Skill values:
  - `C`, `C/R`, `C/R/B` -> `C-Side`
  - `R/B` -> `BD-Side`
  - `Calls&DC` -> `DC&Calls-Side`
  - `Menu Entry` -> `Kfood`
  - `Audit KSA`, `Audit QAT`, `Audit KW`, `Audit BH`, `Appeal KSA`, `Appeal KW`, `Appeal QAT`, `Appeal BH`, `Audit UAE`, `Auditor`, `TBU` -> `CM`
- `LOB Skill` is also recognized automatically as an import column heading.
