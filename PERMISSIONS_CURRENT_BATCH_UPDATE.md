# Permissions update
- Mustafa remains the immutable Main Admin.
- Nesreen receives additional manager access only to the latest active batch whose responsible trainer is Mustafa, via a one-time migration.
- No future Mustafa batch automatically grants Nesreen access.
- Settings > Batch access lets Mustafa add/remove additional trainers per specific batch.
- Additional access does not change Responsible Trainer, Created By, or historical ownership.
