# Role Play + Agent 360 History Update

- Added a **Role Play** tab to every New Hire and Upskill batch.
- Each participant can have unlimited Role Play records with Date, Case ID, Trainer, Result and Notes.
- Case IDs are clickable and copy directly to the clipboard.
- Certification Mock Chat Attempt 1 and Attempt 2 now each have their own Case ID field; saved IDs are clickable-to-copy.
- Clicking participant names throughout the Batch opens a consolidated Agent History view showing batch history, certification attempts, Mock Chat Case IDs, Nesting results, Role Plays and normal Sessions.
- Existing Agents profile now also shows Batch / Certification / Nesting / Role Play history when linked by Agent ID, MIS or HR ID.
- Role Play data and Mock Chat Case IDs are included in Batch Excel export, full/date-range JSON backup and Backup Excel export.
- Role Play editing follows Batch permissions: only the responsible trainer or Mustafa can add/delete Role Plays; others are view-only.
- Existing storage key and prior data are preserved. Older records migrate with empty Role Play / Mock Chat Case ID values.
