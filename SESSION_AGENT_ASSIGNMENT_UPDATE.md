# Session agent assignment update

- Activity keeps the full required-agent audience.
- Creating a session no longer auto-adds every activity agent.
- Session creator selects exactly which still-pending agents belong to that session.
- Search, LOB filter, Select all shown, and Clear shown are available in the session form.
- Any agent already marked Attended in any session under the same activity is automatically excluded from future session selection.
- Agents marked Absent remain available for later sessions until they attend.
- Session attendance roster contains only agents selected for that session.
- A second validation runs when saving to prevent a stale form from scheduling an agent who was covered meanwhile.
