# Session owner edit update

- The responsible trainer for a session can edit that session.
- Mustafa (Main Admin) can edit any session.
- Edit Session allows adding/removing agents from the session roster.
- Current assigned agents remain selectable while editing, including agents already marked Attended in this same session.
- Agents already covered in another session under the same activity are hidden/blocked.
- Newly added agents start as Absent until attendance is updated.
- Removed agents are removed from that session attendance roster; activity coverage recalculates automatically.
- Only the responsible trainer or Main Admin can change attendance or mark the session complete/incomplete.
- Activity is locked while editing an existing session to prevent moving a roster into the wrong activity.
