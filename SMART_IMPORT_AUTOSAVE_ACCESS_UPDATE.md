# Smart Import, Auto-save & Batch Access Update

- Single-tab Batch Import reads only the worksheet matching the current Batch tab; it never falls back to an unrelated worksheet.
- Import All routes recognized workbook worksheets to Information, Attendance, Quiz, Typing Test, Role Play, Certification, Nesting and Result.
- Day/Date recognition remains enabled and participant matching remains HR ID -> MIS/JW -> Name.
- Batch Information, Attendance, Quiz and Typing Test auto-save 5 minutes after the last edit. Manual Save All remains available.
- Batch participant ordering includes Original order / Alphabetical A-Z; Batch Excel export follows the selected ordering.
- Added per-batch additional trainer access controls in Settings for Mustafa.
- Existing Mustafa-owned batches grant Nesreen additional manager access on migration; Mustafa can remove/change access from Settings.
- Additional access does not change the responsible trainer or ownership/history.
