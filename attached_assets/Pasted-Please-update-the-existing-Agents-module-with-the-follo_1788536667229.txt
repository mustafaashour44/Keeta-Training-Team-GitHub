# BULK ENTRY BEHAVIOR

Before saving multiple Agents:

Validate all rows.

Check for duplicate HR IDs.

Check against existing Agents.

Check for duplicate HR IDs inside the new list itself.

Warn if MIS already exists.

Do not save incomplete rows unless the user intentionally leaves a fully blank row.

Fully blank rows should simply be ignored.

If one row contains an error, highlight only that row and explain the problem.

Example:

HR ID 10829 already exists.

Do NOT silently create duplicates.

This is very important because the Training Team already works heavily with Google Sheets.

# DELETE LOGIC

If the Agent has NO Training History:

Allow permanent deletion.

If the Agent already has Training History, Session Attendance, or Activity Coverage records:

Do NOT permanently remove historical records.

Instead show two options:

Deactivate Agent

or

Archive Agent

Recommended behavior:

Archive the Agent so historical data remains available.

The Agent should disappear from the default Active Agents list but remain available in historical Reports and Training records.

Do not break Sessions or Training Activities if an Agent is removed.

# 15. IMPORTANT DATA RULES

HR ID is the main unique identifier.

Never create duplicate HR IDs.

Do not lose Training History when editing an Agent.

Do not lose Training History when changing LOB.

Do not lose Training History when changing Employment Status.

Do not break historical data when deleting or archiving an Agent.

Agents Database remains the source of truth for current Agent Head Count.
